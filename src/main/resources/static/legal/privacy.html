Süni intellekt köməkçisi və üçüncü tərəf emalçılar

Köməkçi funksiyası aktiv olduqda, köməkçiyə yazdığınız mətn (məsələn, «pasportu yataq otağındakı şkafın yuxarı siyirməsinə qoydum») və məkanlarınızın adları cümləni başa düşmək üçün model provayderinə göndərilir. Konfiqurasiyadan asılı olaraq bu, Anthropic (Claude modelləri) və ya OpenAI ilə uyğun API təqdim edən başqa provayder ola bilər. Göndərilən mətn yalnız həmin sorğuya cavab vermək üçün istifadə olunur. Modelin cavabı etibarsız sayılır və yoxlamadan keçməyincə heç nəyə təsir etmir; model heç vaxt verilənlər bazasına birbaşa yazmır — bütün yazılar yalnız serverimiz tərəfindən, sizin öz məlumatlarınız əsasında aparılır. Provayder söndürülübsə, mətn cihazınızdan yalnız bizim serverə gedir.

Köməkçiyə yazdığınız mətnlər istehsal mühitində jurnala yazılmır.

Saxlanma müddəti

Bütün məlumatlar hesabınızı silənə qədər saxlanılır. Hesab silindikdə hesab, məkanlar, yerləşmələr, əşyalar, tarixçə, foto metadata və sessiyalar dərhal silinir; fotoların özləri obyekt yaddaşından qısa müddət sonra asinxron silinir. Şifrələnmiş ehtiyat nüsxələr silinmiş məlumatları ən çox {{BACKUP_RETENTION_DAYS}} gün saxlaya bilər və sonra rotasiya ilə silinir.

whereis — Privacy notice

whereis answers one question: "Where did I put this item?" It collects only what that purpose needs. This notice explains what we store, why, and for how long.

What is collected and why

DataPurpose
E-mail address and a BCrypt password hash (the password itself is never stored) Creating the account and verifying sign-in
First and last name (optional)Account record only; not displayed anywhere
Spaces, locations, items and item movement history The content you enter — the service itself
Item photos Stored in a private object-storage bucket; served only through signed links valid for 10 minutes, only to you
Request log: time, path, status code and X-Correlation-Id Troubleshooting. Passwords, tokens and the text you type into the assistant are never logged

No advertising identifiers, precise location (GPS), contacts or device inventories are collected. No analytics or tracking SDKs are used.

AI assistant and third-party processors

When the assistant feature is enabled, the text you type into it (for example "I put my passport in the bedroom wardrobe top drawer") together with the names of your spaces is sent to the model provider so the sentence can be understood. Depending on configuration this is Anthropic (Claude models) or another provider exposing an OpenAI-compatible API. The text is used only to answer that request. The model's answer is treated as untrusted and has no effect until it passes validation; the model never writes to the database directly — every write is performed by our server against your own data only. If the provider is disabled, the text leaves your device only to reach our server.

Assistant messages are never written to production logs.

Retention

Everything is kept until you delete your account. On deletion the account, spaces, locations, items, history, photo metadata and sessions are removed immediately; the photo files are removed from object storage asynchronously shortly after. Encrypted backups may hold deleted data for up to {{BACKUP_RETENTION_DAYS}} days before rotating out.

Your rights

  • Access: all your data is visible to you inside the app.
  • Correction: every space, location and item can be edited in the app.
  • Deletion: /legal/delete-account — in the app via "Settings → Delete account", or by e-mail.

For anything else, write to {{SUPPORT_EMAIL}}.

Children

whereis is not directed at children under 13 and does not knowingly collect data from them. If we learn of such an account, we delete it.
